# Year 10 Yearly Assessment Materials & Revision Hub

A client-side interactive revision hub and test bank aligned with the **NSW Stage 5 Australian Curriculum** (Year 10 level) for Picnic Point High School. Built with pure HTML/CSS/JavaScript with zero external dependencies.

---

## 🗂️ Repository Structure

```text
├── Portal.html                 # Central interactive study hub & subject navigation
├── Due Dates.html              # Chronological assessment calendar & task notifications
├── Schedule.html               # 4-week interactive study timetable
├── Cheat Sheet.html            # Formulas, collision theory templates & PETAL writing guide
├── English/
│   └── Test.html               # 25 unseen dystopian fiction reading extracts & analysis
├── Science/
│   ├── Test.html               # 36 scenario-based questions (Genetics, Reactions, Space, Skills)
│   └── Drill.html              # 40-question rapid-fire recall drill
└── Mathematics/
    ├── Test.html               # 25 Stage 5.3 applied scenarios (Quadratics, Polynomials, Probability)
    └── Drill.html              # 30-question high-yield problem drill
```

## 🚀 Getting Started

No build tools, package managers, or local servers are required:
1. Clone or download this repository.
2. Double-click **`Portal.html`** in your file manager to open it in any web browser (Chrome, Edge, Safari, Firefox).
3. Navigate to interactive practice tests, drills, or formula cheat sheets.
