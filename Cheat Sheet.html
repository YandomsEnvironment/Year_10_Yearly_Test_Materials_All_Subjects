1. Analytical Paragraph Framework (PETAL)
Point: The author critiques [oppression/conformity] by demonstrating how [element] restricts individual autonomy.
Evidence: This is evidenced when "[short 3-4 word quote]".
Technique: The composer employs [sensory imagery / metaphor / juxtaposition / motif]...
Analysis: ...specifically through the diction "[key word]", which conveys [dehumanisation/surveillance/control].
Link: Ultimately, this reinforces the text's warning that [loss of identity / totalitarian conformity] erodes humanity.
  • Analytical Verbs: dismantles, illuminates, encapsulates, subverts, underscores, reinforces.
    • 2. Creative Writing: 4-Step Narrative Progression
    • Step 1 (The Routine): Ground the setting with character immersion in a routine civic duty or mechanical task under surveillance.
    • Step 2 (The Anomaly): Introduce an organic or forbidden discovery (a seed, a handwritten fragment, an uncalibrated lens).
    • Step 3 (The Tension): A checkpoint, patrol, or biometric scan approaches; the protagonist decides to conceal the item.
    • Step 4 (Internal Subversion): The external regime remains unchanged, but the protagonist maintains internal autonomy and awareness.

    1. Working Scientifically: Core Methodological Criteria
    How to improve RELIABILITY:
    → "Repeat the trial 3 to 5 times under identical conditions, remove any anomalous outliers, and calculate an average (mean)."

    How to improve VALIDITY:
    → "Keep it a fair test by testing only ONE independent variable, keeping all other variables strictly controlled, and using a control group for baseline comparison."

    How to improve ACCURACY:
    → "Use measuring equipment with finer increments (e.g. measuring cylinder instead of a beaker), and read the liquid meniscus at eye level to eliminate parallax error."
    2. Collision Theory: 3-Sentence Explanatory Template
    1. Particles: "Higher [temperature/concentration] increases the [speed / particles per volume]."
    2. Collisions: "This increases the frequency of collisions between reacting particles."
    3. Energy: "More collisions have enough activation energy (Ea) to react successfully, increasing the reaction rate."
    3. Core Chemistry Reactions & Tests
    • Acid + Metal → Salt + Hydrogen gas (Test: Squeaky 'Pop' with lit splint)
    • Acid + Carbonate → Salt + Water + Carbon Dioxide (Test: Turns limewater milky)
    • Acid + Base → Salt + Water (Neutralisation reaction)
    • DNA Base Pairing: A pairs with T, and C pairs with G.

    1. Quadratic Equations & The Discriminant (Δ = b² - 4ac)
    Null Factor Law: If (x - p)(x - q) = 0, then x = p or x = q.
    Discriminant Rules:
    • Δ > 0: 2 distinct real roots (graph cuts x-axis twice).
    • Δ = 0: 1 repeated real root (vertex touches the x-axis, tangent).
    • Δ < 0: 0 real roots (parabola floats above or below x-axis without touching).
    2. Functions & Polynomial Theorems
    Remainder Theorem: When P(x) is divided by (x - a), the remainder is simply P(a).
    Factor Theorem: (x - a) is a factor if and only if P(a) = 0.
    Vertical Line Test: If any vertical line cuts a graph more than once, it is NOT a function (e.g. circles are not functions).
    3. Multistage Probability Shortcuts
    • The 'At Least One' Trick: P(At least 1) = 1 - P(None). Always calculate zero successes and subtract from 1!
    • Without Replacement: Always drop the total number on the second draw (e.g. 5/8 then 4/7).
    • Direct Variation: y = kx (straight line through the origin).
